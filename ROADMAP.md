# Roadmap

## Phase 1: Quick Wins (Next)

| Feature | Status | Description |
|---------|--------|-------------|
| HD voice option (`tts-1-hd`) | Planned | Higher quality audio at $30/1M chars |
| Audio normalization (ffmpeg) | Planned | Professional loudness standards |
| Multiple formats (MP3/Opus/AAC) | Planned | Better compatibility options |

## Phase 2: File Upload & Text Extraction

| Feature | Status | Description |
|---------|--------|-------------|
| **Drag & drop file upload** | **Planned** | Upload files directly to the UI |
| PDF text extraction | Planned | Extract text from PDF documents |
| Word document support (.docx) | Planned | Extract text from Word files |
| Plain text files (.txt, .md) | Planned | Direct text file support |
| URL content extraction | Planned | Fetch and extract text from web pages |
| Image OCR | Future | Extract text from images |

| Feature | Status | Description |
|---------|--------|-------------|

| AI script generation (GPT-4) | Planned | Generate dialogue from topics |
